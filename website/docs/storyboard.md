# 官網分鏡與內容邊界

## 受眾與目標

面向使用 Windows 工作的人，重點情境是重用 AI 提示詞、常用回覆、研究素材與技術片段。讓訪客看懂程式能做什麼、如何使用，再下載安裝版或可攜版。AI 是使用情境，並非產品內建功能。

## 視覺

主參考：<https://appycamper.com/>，2026-09-08 查核。

保留深色大字、留白、漂浮圖片與逐段觀看的氣質。官網採深石墨 `#111312`、近白 `#f0f0e9`、橘紅 `#ff573b`；綠灰與暖色用於示意卡片及下載收尾。產品面板維持灰階、靛藍。使用 Mnemark 的堆疊 icon，作者顯示名稱為 IA_LiuT。

SkillUI 的輸出只能當索引。其「沒有動畫框架」與字型角色辨識不完整：瀏覽器確認實際字型為 Funnel Display，Webflow ix2 提供捲動及循環動效，頁面另載入 Lenis。這些來源資訊不等於 Mnemark 要沿用原網站 runtime。

## 章節

| 區域 | 敘事任務 | 主要狀態與交接 |
|---|---|---|
| 首屏 | 一眼辨識工具，立即能下載 | 標題與 CTA 不動，背景工作片段向上循環；自然捲入介紹 |
| 介紹 | 解釋重複尋找與複製的問題 | 照常複製 → Ctrl+Shift+V → 搜尋選取 → Enter 貼回 |
| 功能 | 從能力介紹轉為具體教學 | 記錄、搜尋貼回、抽屜、釘選、預覽備註、批次、設定七章；每章四個操作狀態 |
| 適用對象 | 讓不同工作者認出自己的需求 | AI 使用者、行政客服、研究創作、開發技術四類 |
| 工作流 | 把功能放回真實工作情境 | 四張橫向卡片，各含起因、三步操作與具體收益；明示不是使用者評價 |
| 製作者 | 提供可信且可查證的來源 | IA_LiuT 字樣、製作者身分與 GitHub；不補造履歷或照片 |
| 下載收尾 | 完成下載選擇與第一次使用 | 安裝版為主、可攜版為次；需求、差異與三步上手 |

## 互動與替代

桌面七章依序完整展示，不以 tab 隱藏其他功能。固定導覽能跳至主要區域；語言切換保留當前章節。各個 demo 使用相同 normalized progress 推導畫面，避免倒退時資料狀態不同步。

寬度小於 1100px 或高度小於 600px：直式閱讀；每個 demo 由使用者播放、暫停及重播；離開畫面就暫停。一般筆電 1366×657 仍使用完整捲動模式。工作流卡片可水平滑動、按前後鈕或在焦點內使用方向鍵。

2026-09-09 使用者修訂：背景預設持續播放、移除動態調整按鈕，不再讀取舊的 localStorage 或系統動態偏好來停用動畫。背景只在首屏不可見或頁籤隱藏時暫停。沒有 JavaScript 時仍有完整內容、原生 details 與下載連結。

功能區另有可逆的圖片進場：由下方 30vh、-10° 傾斜移至定位，使用較晚的進場區間讓傾斜在圖片真正可見時發生。每章展示距離延長為 280svh；前一章固定在導覽列下方，後一章由下往上完整覆蓋，直到整個功能區結束才解除固定。七章分別使用不同的工作畫面、來源內容與可見操作，避免重複展示同一份剪貼簿清單。手動播放每段由 8 秒延長至 11 秒。

## 驗證依據

產品事實來源：README、CONTEXT、src/i18n.ts、src/dataset.ts、src/styles.css 及目前 release。網站是教學式重建，沒有接入桌面剪貼簿，也不表示可以在網頁使用原程式功能。

釘選最多 10 則；容量可調整但並非無限；檔案不備份；來源排除不是全面敏感資料偵測；歷史預設非持久化、抽屜獨立保存。完整限制放在可展開清單與相關章節旁。
