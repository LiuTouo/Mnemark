# 官網分鏡與內容邊界

## 受眾與目標

面向使用 Windows 工作的人，重點情境是重用 AI 提示詞、常用回覆、研究素材與技術片段。讓訪客看懂程式能做什麼、如何使用，再下載安裝版或可攜版。AI 是使用情境，並非產品內建功能。

## 視覺

主參考：<https://appycamper.com/>，2026-09-08 查核。

保留深色大字、留白、漂浮圖片與逐段觀看的氣質。官網採深石墨 `#111312`、近白 `#f0f0e9`、橘紅 `#ff573b`；綠灰與暖色用於示意卡片及下載收尾。產品面板維持灰階、靛藍。使用 Mnemark 的堆疊 icon，作者顯示名稱為 IA_LiuT。

可讀性調整：大主標題保留原比例，小字普遍增加 3px；功能解說為桌面 17px、窄視窗至少 16px，補充說明至少 13px。demo 內文字也放大，容器增高以避免裁切。固定工作流區把前置留白移到區塊外，確保較大文字能完整留在視窗內。

SkillUI 的輸出只能當索引。其「沒有動畫框架」與字型角色辨識不完整：瀏覽器確認實際字型為 Funnel Display，Webflow ix2 提供捲動及循環動效，頁面另載入 Lenis。這些來源資訊不等於 Mnemark 要沿用原網站 runtime。

## 互動與替代

頁面滾輪使用 Lenis 平滑捲動，約 1.05 秒減速收尾，與 GSAP 共用更新時鐘。停止滾輪後畫面短暫滑向目標，產品 demo 的自動播放不受影響。手機維持原生觸控捲動。

桌面七章依序完整展示，不以 tab 隱藏其他功能。固定導覽能跳至主要區域；語言切換保留當前章節。產品 demo 使用自己的播放時鐘，畫面可見即自動循環，停止捲動仍會繼續；捲動不再快轉、倒帶或重設 demo。

寬度小於 1100px 或高度小於 600px：直式閱讀；demo 同樣自動循環，保留暫停／續播與重播控制。離開畫面、被下一章完全覆蓋或頁籤隱藏時暫停，返回後接續原位置。一般筆電 1366×657 仍保留完整章節固定與覆蓋動效。工作流卡片可水平滑動、按前後鈕或在焦點內使用方向鍵。

2026-09-09 使用者修訂：背景預設持續播放、移除動態調整按鈕，不再讀取舊的 localStorage 或系統動態偏好來停用動畫。背景只在首屏不可見或頁籤隱藏時暫停。沒有 JavaScript 時仍有完整內容、原生 details 與下載連結。

功能區另有可逆的圖片進場：由下方 30vh、-10° 傾斜移至定位，使用較晚的進場區間讓傾斜在圖片真正可見時發生。每章展示距離為 125svh；前一章固定在導覽列下方，後一章由下往上完整覆蓋，直到整個功能區結束才解除固定。七章分別使用不同的工作畫面、來源內容與可見操作。每輪包含 9.5 秒操作及 0.44 秒接回開頭的過渡，自動重複，不必操作播放按鈕。

每章由原先 280svh 縮為 125svh，減少約 55% 的切換捲動距離。這只改變章節之間的距離，不改變獨立的 demo 播放速度。

## 驗證依據

產品事實來源：README、CONTEXT、src/i18n.ts、src/dataset.ts、src/styles.css 及目前 release。網站是教學式重建，沒有接入桌面剪貼簿，也不表示可以在網頁使用原程式功能。

釘選最多 10 則；容量可調整但並非無限；檔案不備份；來源排除不是全面敏感資料偵測；歷史預設非持久化、抽屜獨立保存。完整限制放在可展開清單與相關章節旁。
