# scroll-product-chapter

## 來源確認

參考 <https://appycamper.com/> Services 區。DOM 存在 `.services-sticky` 的逐項三欄布局；瀏覽器確認 position: sticky。Webflow `a-16` / `Sticky-in` 使用 scroll progress 將圖片從 y:30vh、rotation:-10deg 送至 y:0、rotation:0。

## 本站設計

每章是完整 semantic section，含名稱、標題、解說、四步操作、能力邊界與產品示意。寬度至少 1100px、高度至少 600px 時，每章高度 125svh，以較長捲動距離呈現內容。stage 自 top:88px 起固定，直到整個 `.feature-chapters` 容器結束才解除；使用 pinSpacing:false，章節本身負責預留展示距離。下一章是較高層級的不透明平面，由下往上覆蓋前一章；前一章不隨交接移動。捲動只控制場景，產品操作由獨立時間軸自動循環，沒有綁定 ScrollTrigger 的播放進度。

2026-09-09 修訂：產品容器另使用入場進度，從 y:30vh、rotation:-10deg 轉正歸位。入場範圍由章節 top 抵達視窗 60% 開始，到 top:88px 完成，easing 為 power1.out；這是為了讓圖片進入畫面後仍看得到轉正過程，而不是在畫面外就結束。文字使用獨立的短距離上移，後一章依 z-index 與背景覆蓋前一章。

| 操作時間進度（7 秒） | 狀態 |
|---|---|
| 0–0.15 | 起始畫面，提供閱讀與準備時間 |
| 0.15 | 操作第二狀態，開始搜尋／分類等動作 |
| 0.475 | 操作第三狀態，選取／拖入等動作 |
| 0.8–1 | 完成狀態與閱讀停留 |

狀態交界以 0.035 個進度單位交叉淡化，偏移不超過 5px。搜尋有文字揭示，抽屜有拖入路徑。四份快照使用相同位置的面板結構；可見框、操作步驟標示與進度條由相同 progress 推導。

完成後以 0.44 秒交叉淡化至開頭的相同畫面，再進入下一輪。開頭橋接圖層不參與四步操作或輔助閱讀，並在媒體條件重建時移除。循環不倒播貼上／刪除等操作。只播放畫面可見的 demo；固定章節即使幾何上仍在畫面內，也要檢查是否已被下一章覆蓋。暫離畫面會暫停並保留位置。

素材為教學式產品 UI 重建及固定示範資料。所有元件都不執行真實貼上、保存或剪貼簿讀取。欄位名稱與操作能力以目前 Mnemark 為準。

可調：每章捲動長度、狀態閾值、過渡距離、面板比例。各章資料由 locale 字典供應，不能在 animation callback 中累加不可逆內容。

七種示範具有不同起始畫面：素材來源卡、AI 對話編輯器、抽屜側欄、常用回覆、預覽工作區、多選工具列、淺色設定。操作包含面板出場／退出、搜尋揭示、拖入、釘選上移、側欄展開、備註對話框、多選與保存切換；以共享面板外觀保持產品一致性，不共享同一份清單當作全部示範。

手機／極短視窗：取消固定，使用 -4°／10vh 的較小入場；與桌面一樣自動循環播放，每輪 7 秒操作加 0.44 秒交接。所有尺寸都提供暫停／續播與重播，但不需要按播放才開始。

## 驗收

不捲動時，demo 仍推進並自動進入第二輪；正反捲動不能改寫播放時間。循環接點不得露空白，離場暫停、返場續播，使用者暫停後不得被捲動擅自恢復。切換語言、縮放、開啟完整功能清單後重新量測。清單可視區可以裁切長清單，面板框與底部操作列必須保留在 demo 內。

交接另測三個位置：下一章 top 為 550px、300px、88px 時，前一章 top 都必須為 88px；下一章下緣以內的命中測試必須由下一章覆蓋。離開整個功能區後解除全部固定，不遮擋後續內容。
