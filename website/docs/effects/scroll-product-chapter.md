# scroll-product-chapter

## 來源確認

參考 <https://appycamper.com/> Services 區。DOM 存在 `.services-sticky` 的逐項三欄布局；瀏覽器確認 position: sticky。Webflow `a-16` / `Sticky-in` 使用 scroll progress 將圖片從 y:30vh、rotation:-10deg 送至 y:0、rotation:0。

## 本站設計

每章是完整 semantic section，含名稱、標題、解說、四步操作、能力邊界與產品示意。桌面每章高度 220svh，stage 固定於 88px 導覽下方。單一 progress ∈ [0,1] 是唯一狀態来源，ScrollTrigger scrub:true 不加入時間延遲。

| 進度 | 狀態 |
|---|---|
| 0–0.15 | 起始畫面，提供閱讀與準備時間 |
| 0.15 | 操作第二狀態，開始搜尋／分類等動作 |
| 0.475 | 操作第三狀態，選取／拖入等動作 |
| 0.8–1 | 完成狀態與閱讀停留 |

狀態交界以 0.035 個進度單位交叉淡化，偏移不超過 5px。搜尋有文字揭示，抽屜有拖入路徑。四份快照使用相同位置的面板結構；可見框、操作步驟標示與進度條由相同 progress 推導。

素材為教學式產品 UI 重建及固定示範資料。所有元件都不執行真實貼上、保存或剪貼簿讀取。欄位名稱與操作能力以目前 Mnemark 為準。

可調：每章捲動長度、狀態閾值、過渡距離、面板比例。各章資料由 locale 字典供應，不能在 animation callback 中累加不可逆內容。

手機／短視窗：取消 sticky；同時間軸以 8 秒播放，由按鈕控制。離開章節或頁籤不可見時暫停。reduced motion 顯示最後狀態與完整步驟、不自動播放。

## 驗收

每章在 0、0.25、0.5、0.75、1 進度比對，並以反向順序重走。迅速跨章不殘留圖層。切換語言、縮放、開啟完整功能清單後重新量測。清單可視區可以裁切長清單，面板框與底部操作列必須保留在 demo 內。
