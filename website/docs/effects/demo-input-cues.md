# demo-input-cues

所有教學維持 7 秒操作加 0.44 秒循環過渡。操作提示與畫面使用相同時間軸，捲動不決定示範進度。

## 輸入示意

- 每個 demo 只有一個游標，跨畫面連續移動；點擊前先抵達目標，按下時出現波紋與目標框線。
- 游標位置由實際 DOM 控制項量測，反算插圖的旋轉矩陣，避免視窗尺寸、字型或傾斜進場造成指錯位置。
- 懸停預覽不顯示點擊波紋，明示「不需點擊」。
- 拖曳分成移到把手、按住左鍵、拖入、放開；游標和卡片共同移動，放開後顯示保存結果。
- 快捷鍵使用按鍵標籤與按下高亮；搜尋流程依序標示 Ctrl+Shift+V、/、輸入文字、↓、Enter。複製內容顯示 Ctrl+C。
- 打字逐字顯示；建立抽屜、備註與主題選擇保留必要的選單／確認操作。
- 提示列固定高度，不因按鍵標籤出現而推動整個插圖。
- demo 至少約 85% 位於畫面內、且未被下一章大幅遮住時才播放，避免第一個動作在可視區外播完。

## 各章腳本

| 章節 | 可見操作 |
|---|---|
| 內容記錄 | Ctrl+C 複製文字與圖片 → Ctrl+Shift+V 開啟歷史 → 點圖片分類 |
| 額外搜尋 | Ctrl+Shift+V → / 聚焦 → 輸入摘要 → ↓ 選取 → Enter 貼回 |
| 抽屜分類 | 點新增 → 輸入名稱 → 點建立 → 按住把手拖入 → 放開保存 |
| 釘選 | 點項目釘選 → 在其他程式 Ctrl+C → 點釘選項目的複製按鈕 |
| 預覽備註 | 懸停預覽 → 點更多 → 點備註 → 輸入提醒 → 點儲存 |
| 批次整理 | 開多選 → 依序勾選三筆 → 點加入抽屜 → 選專案素材 → 保存 |
| 設定 | 點主題選單 → 選深色 → 開啟歷史保存 → 向下捲動查看排除程式 |

批次 demo 聚焦分類保存；刪除與復原仍在完整功能說明中，不以沒有操作提示的畫面變化帶過。所有操作皆為網站示意，不讀寫訪客剪貼簿或操作桌面程式。
