## 來源確認

參考 <https://appycamper.com/> 首屏。2026-09-08 從瀏覽器 Webflow ix2 actionLists 讀取：`a-4` / `Cloud-loop` 令 `.cloud-row` 從 `y: 0%` 移到 `-50%`，duration 45000ms；`a-7` / `Cloud-in` 為另外的進場動畫。頁面截圖確認標題位於圖片上方。這是原始設定證據，非由七張靜態截圖猜測 easing。

## 本站設計

輸入：時間；輸出：每條卡片軌道的 yPercent。每條包含相同內容的兩組，45 秒移動半個循環，線性重複。三條軌道使用錯位起點與不同排列，外層保持固定角度。標題、按鈕與導覽不移動。

素材：原創提示詞、圖片、程式碼、檔案、筆記、連結六種卡片；不需要遠端圖片或 canvas。裝飾容器 aria-hidden，不能取得焦點。

可調：45 秒週期、軌道位置／角度、卡片間距、不透明度、中心遮罩。修改間距時必須維持兩份內容及循環距離一致，避免接縫。

暫停：首屏不在畫面或 document.hidden 時暫停，返回後延續。依 2026-09-09 使用者修訂，背景預設播放，不設動態開關，也不讀取舊儲存值或系統動態偏好來關閉背景。行動版保留較淡、較少可見的背景。

## 驗收

觀察一個完整週期；末端不能閃回或露空。CTA 與標題不可被背景遮蔽。頁籤隱藏或首屏離場後停止更新。即使舊 localStorage 保有 reduced 值，重新載入仍應自動播放。
